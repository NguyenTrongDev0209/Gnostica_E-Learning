---
description: Steps to start the Gnostica project development environment.
---

### 1. Start Backend
1. Open a terminal in `d:\Gnostica_E-Learning\gnostica-server`.
2. Run: `./mvnw spring-boot:run`

### 2. Start Web Frontend
1. Open a terminal in `d:\Gnostica_E-Learning\gnostica-web`.
2. Run: `npm run dev`

### 3. Start Mobile App
1. Open a terminal in `d:\Gnostica_E-Learning\gnostica-mobile`.
2. Run: `npx expo start`
